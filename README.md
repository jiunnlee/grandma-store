## 檔案
- `src/engine.js` 純邏輯引擎（瀏覽器與 Node 共用）
- `src/data.js` 篇章一的關卡、商品、事件卡、圖鑑、台詞；`src/data2.js` 篇章二；`src/data3.js` 篇章三（含 `D.market` 虛構商品與每關的 `market.script` 劇本）；`src/data4.js` 篇章四（假平台商品有 `fake`、`freezeFrom`，劇本用 `mult: 0` 讓平台消失）。新增關卡或事件只改這些檔
- `src/scene.js` 等距小店場景（SVG）
- `src/ui.js`、`src/style.css` 介面
- `build.js` 合併成 `dist/index.html`（Artifact 用）與 `dist/standalone.html`（本機直接開）
- `test/balance.js` 自動平衡測試；`test/playthrough.js` 用 Playwright 自動玩一關並截圖到 `dist/shots/`

```
node build.js && node test/balance.js && node test/playthrough.js
```

## 數值設計要點
- 客人數 = 基礎客數 × (0.5 + 人氣/100) × 天氣／事件倍率 × 價格因子 × 雜訊
- 價格因子：便宜增客慢（0.8 次方）、貴掉客快（1.8 次方）
- 所有亂數由（種子, 天數, 用途）決定，與玩家先前的選擇無關，平行世界才公平
- 過關門檻：輕鬆 0.6×、標準 1×、挑戰 1.2×（挑戰另有房租 1.15× 與事件 20 秒倒數）
- 市場：每天價格 = 前一天 × (1 + 趨勢 + 雜訊 × 難度係數) × 劇本倍率；雜訊由（種子, 天數, 商品）決定。融資最多三倍、利息每天 0.5%、持股低於欠款 1.3 倍斷頭（不會負債，但信用 −15、壓力 +30）
